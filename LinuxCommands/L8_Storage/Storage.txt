1) Disk Usage (Directory/File Level)

It Shows size of directories or file
#du = Disk Usage

		du -h filename.txt

		du -h /directory/sub_directory 

		where -h represents the MB size

Example:
	du -h /home
Output :
	2.0G    /home/user1
	500M    /home/user2
	2.5G    /home



2) Disk Free (Filesystem Level) ?


It Shows the disk space usage of entire filesystem 
#df = disk free

Example:
	df -h
Output : 
	Filesystem      Size  Used Avail Use% Mounted on
	/dev/sda1        50G   35G   13G  73% /


Note : 
	du = directory
	df = filesystem
