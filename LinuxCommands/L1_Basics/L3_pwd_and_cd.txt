2) cd (Change Directory)

		How Do i go back in the parent directory ?

			cd ..

		How Do i go double parent back in the directory ?

			cd ../..
		
		How to use current directory ?

			cd .

		How Do i Direction into home ?

			cd ~

		How Do i Direction into ROOT ?

			cd /
		
		How Do i go to previous directory ?

			cd -
